## Проект "Пугливые блоки"
Сказал блок вслух - и он в твоем чанке он пропадет

Автор `HomaPlus`
Разработано по заказу `Nuko02`. **Не подлежит перепродаже**

### Клиентская часть
Мод для Fabric 1.21.8 (0.136.1+1.21.8)
Микрофон должен поддерживать частоту 22050гц в 16бит
Дополнительная конфигурация отсутствует

### Серверная часть
Плагин для 1.16.5 - 1.21.8 (Протестированные версии)

#### Конфигурация `config.tson` tson 2.0 (поддержка математики, рефлектора и скриптов)
```c
{
  main = {
    main.model-dir = "model", //путь для модели относительно папки с плагином
    //доступные модели - https://alphacephei.com/vosk/models, скачать и распоковать 
    
    max-words = 4, //максимальный размер буфер слов
    words-queue = 2, //максимальный размер слов вне буфера
    audio-rate = 22050 //необходимо, чтобы было синхронизировано с модом
  },
  pool = {
    threads = 1,    //стартовое количество потоков для аудио-ИИ-служб
    max-threads = 3 //максимальное количество потоков для аудио-ИИ-служб
  },
  
  words = {
    //полный список материалов https://advancedplugins.net/spigot-material-list
	stone = "камень;большие ножницы;бумага" //ключевые фразы разделить `;`
  }
}
```
